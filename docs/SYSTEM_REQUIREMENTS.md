# 豆苗プランター システム要件定義書

## 1. プロジェクト概要

### 1.1 プロジェクト名
**豆苗プランター (Bean Sprout Planter)**

### 1.2 プロジェクト目的
豆苗栽培に特化した自動植物育成システムの開発。AI判断、センサー監視、自動給水、カメラ撮影、通知機能を統合した包括的なソリューションの提供。

### 1.3 プロジェクトスコープ
- 豆苗栽培の完全自動化
- Raspberry Pi 5ベースのハードウェア制御
- Webベースの管理インターフェース
- AI判断による収穫タイミング判定
- 多層化栽培への対応

## 2. システム要件

### 2.1 機能要件

#### 2.1.1 センサー監視機能
- **温湿度センサー (AHT25)**
  - I2C通信による温度・湿度測定
  - 測定範囲: 温度 -40°C〜85°C、湿度 0%〜100%
  - 測定精度: 温度 ±0.3°C、湿度 ±2%RH
  - 測定間隔: 30分間隔

- **水圧センサー (MS583730BA01-50)**
  - 水圧測定による給水判定
  - 詳細仕様は今後決定予定


#### 2.1.2 自動給水機能
- **給水判定**
  - 詳細仕様は今後決定予定

- **給水制御**
  - 給水量: 100ml/回
  - 給水時間: 5秒間
  - タンク残量管理
  - ユーザーのWebからの入力によって変更可能

- **タンク管理**
  - 容量: 2000ml
  - 低水位警告: 200ml以下
  - 残量計算と補充管理

#### 2.1.3 カメラ撮影機能
- **単一カメラ管理**
  - USBカメラ対応
  - 解像度: 1280x720
  - 自動撮影: 毎日6:00
- **注意**: 多層カメラ制御は一時停止

#### 2.1.4 AI判断機能
- **収穫判断**
  - 画像とセンサーデータの統合分析
  - 成長段階判定
  - 収穫タイミング予測

- **病気診断**
  - 画像解析による病気検出
  - 対処法・予防法提案

- **調理例提案**
  - 収穫データに基づく調理例
  - 栄養情報提供

- **一般相談**
  - 豆苗栽培に関する質問対応
  - マルチモーダル対応（画像+テキスト）

#### 2.1.5 Web管理インターフェース
- **ダッシュボード**
  - リアルタイムセンサーデータ表示
  - システム状態監視
  - 統計情報表示

- **AI相談画面**
  - チャット形式の相談
  - 画像アップロード機能
  - 相談履歴表示

- **カメラ管理画面**
  - 撮影画像表示
  - 撮影スケジュール設定
  - 画像履歴管理

- **給水タンク画面**
  - タンク状態表示
  - 手動給水・補充
  - 給水履歴表示

- **成長記録画面**
  - センサーデータグラフ
  - 成長記録管理
  - 統計分析

- **設定画面**
  - システム設定変更
  - センサー閾値設定
  - 通知設定

#### 2.1.6 通知機能
- **LINE Notify連携**
  - 栽培状況報告
  - アラート通知
  - 画像付き通知

- **メール通知**
  - SMTP経由での通知
  - 複数宛先対応

- **システム通知**
  - ログベースの通知
  - エラー通知

## 3. システム構成

### 3.1 ハードウェア構成
- **メインコンピュータ**: Raspberry Pi 5
- **センサー**:
  - AHT25温湿度センサー（I2C）
  - MS583730BA01-50水圧センサー
  - フロートスイッチ（GPIO）
- **カメラ**: USBカメラ
- **給水システム**: ポンプ + タンク
- **電源**: ACアダプター

### 3.2 ソフトウェア構成
- **OS**: Raspberry Pi OS
- **ランタイム**: Python 3.11
- **Webフレームワーク**: Flask 2.3.3
- **データベース**: SQLite3
- **スケジューラー**: APScheduler
- **画像処理**: OpenCV
- **AI API**: OpenAI GPT-4 / Claude / Gemini

### 3.3 ネットワーク構成
- **ローカルネットワーク**: Wi-Fi/Ethernet
- **ポート**: 8080（Web UI）
- **API**: RESTful API
- **外部連携**: LINE Notify API
